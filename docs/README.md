# Referencias de diseño

Material de consulta, **fuera de `public/`** a propósito: no debe publicarse
con el sitio.

| Carpeta | Qué es |
| --- | --- |
| `lineagrafica/` | Línea gráfica heredada (app Savvi). De aquí salen la escala de espaciado, los radios y la estructura de tokens; **el color ya no**: el blog usa una paleta oscura propia definida en `src/styles/global.css` |
| `plantilla_blog/` | Plantilla HTML de la que salen los bloques del blog (tarjetas, railes, índice, newsletter). Depende de un design system externo; aquí solo se usó como referencia estructural |
